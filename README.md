## Features

- **红绿灯榜**：9 款产品按配料分 🟢（宝矿力/外星人/尖叫）🟡（佳得乐/农夫/东鹏/海之言）🔴（脉动/健力宝）
- **整瓶糖量可视化**：谁超 WHO 25g 上限一目了然（东鹏 37.7g 最高）
- **场景推荐器**：>1h 含糖等渗 / <1h 白水 / 久坐别碰 / 腹泻 ORS / 减脂 0 糖 / 晚场喝茶
- **科学卡片**：SGLT1（糖是钠的搬运工）/ 汗钠 805mg/L / 抽筋真相（疲劳为主）/ 赛前 15-45min 勿吃快碳
- **补剂排行**：AIS ABCD 分级——水>香蕉>肌酸>咖啡因>蛋白质 / 不推荐 BCAA/ZMA/能量饮料
- **运动日补给时间线**：从赛前 60min 到第二天早上，六个节点该做什么
