场景推荐

不是所有运动都需要运动饮料——选错场景要么白喝糖，要么缺钠。

🏸

打球 1 小时以上（出汗多）

✅ 含糖等渗款（宝矿力 / 佳得乐 / 尖叫含糖版）
汗钠流失 ~805mg/L（ACSM），白水补不上。含糖 4-8%＋钠 20-30mmol/L 是 SGLT1 吸收黄金区间。等热身出汗后再喝，别开场就灌。
🏓

打球不到 1 小时（微微汗）

✅ 白水即可，或 0 糖电解质水（外星人）
不到 1 小时的运动钠流失有限，白水够了。想喝有味道的选 0 糖——不额外摄入游离糖。
💻

久坐日常 / 办公室

✅ 白水 / 淡茶，别碰运动饮料
不运动时不需要补钠补糖——喝运动饮料＝纯喝糖水。一瓶东鹏 37.7g 糖 ≈ 1.5 罐可乐的量。
🤒

腹泻 / 挂吐后补水

✅ 含糖等渗款（ORS 同原理）
SGLT1 钠-葡萄糖协同转运正是口服补液盐的机制——糖驱动钠吸收。0 糖电解质水虽然含钠但吸收慢半拍。
💪

减脂期运动

✅ 0 糖电解质水（外星人 / 尖叫 0 蔗糖版）
减脂期控制游离糖——运动饮料一瓶 25-38g 糖直接吃掉一天预算。0 糖版补钠不补糖。但如果运动超 1.5h，少量含糖反而帮你练得更久。
🌙

晚场打球需要提神

✅ 乌龙茶/绿茶（咖啡因 20-50mg）
咖啡因半衰期 ~5h，晚上喝咖啡影响睡眠。赛前 60 分钟 3mg/kg 是最佳时机（~70kg 成人 ≈210mg ≈ 一杯中杯美式）。晚场改喝茶——低剂量提神不留「咖啡债」。
为什么科学

四个反直觉的科学事实——知道之后你会重新选择手里的那瓶。

🔬 糖是钠的「搬运工」

肠道吸收钠的主要通道是 SGLT1（钠-葡萄糖协同转运蛋白）——每个钠离子需要搭一个葡萄糖或半乳糖才能过墙。这就是口服补液盐（ORS）含糖的原因：不是给你能量，是帮你吸钠。0 糖电解质水有钠但吸收慢半拍——果糖走 GLUT5 通道、不驱动 SGLT1。

等渗黄金区间：碳水 4-8% + 钠 20-30mmol/L（宝矿力 6.2%、佳得乐 6.0% 正压甜点）

🧂 钠才是汗液流失大头

汗液中钠均值 ~805mg/L（ACSM，范围 230-1600）——一小时大汗流失约 1g 盐。钾虽然也流失，但补钾效率极低：一根香蕉（350mg）> 1L 宝矿力（210mg）。钙镁写在配料表上更多是营销卖点——运动流失量微乎其微。

国标运动饮料：钠 5-120mg/100ml · 钾 5-25mg/100ml

🔥 抽筋的真相：疲劳为主，电解质为催化

肌肉抽筋的共识机制是神经肌肉疲劳（神经对肌肉的控制力下降），电解质失衡是催化剂、脱水达体重 2% 是触发器。所以：打球前中后补够水＋钠，赛后 15 分钟到回家 1 小时是电解质回填黄金窗——拉伸时抽筋往往就缺这一口。

如果你赛后拉伸经常抽筋：不是缺钙，是离场前没补钠

🍬 赛前 15-45 分钟别吃快碳

赛前 15-45 分钟摄入快速碳水（糖/能量胶/运动饮料）会引发反应性低血糖——胰岛素飙升导致开赛时血糖反而更低、更累。正确做法：赛前 60 分钟以前喝/吃完，让胰岛素回落后再上场；或者等热身出汗后再补——运动中胰岛素敏感度升高，不易低血糖。

咖啡因同理：赛前 60min 3mg/kg 最佳，别临场猛灌
补剂排行

AIS（澳大利亚体科所）ABCD 循证分级——A=有证据支持，B=待定，C=缺乏证据，D=不推荐。按性价比排。

A
水/电解质运动饮料就是你的「补剂」

如果只能选一种「补剂」，就是水＋电解质。其他一切建立在水分充足之上。

A
香蕉 🍌赛前/赛中 1 根

RCT 证明与 6% 碳水运动饮料等效——且附带纤维＋钾（350mg > 1L 宝矿力）＋维生素。性价比之王。

A
肌酸（Creatine）3-5g/天，日常持续

被研究最充分的力量/爆发力补剂，安全性极佳。不需要「冲击期」，每天一小勺即可。对羽毛球/匹克球的急停急转爆发力有直接帮助。

A
咖啡因3mg/kg 赛前 60min

最强合法「兴奋剂」。~70kg 成人 ≈210mg（中杯美式）。半衰期 5h——晚场改乌龙/绿茶（20-50mg），提神不留睡眠债。

A
蛋白质（全天总量）1.4-1.8g/kg/天

不需要精确到每餐——全天总量比「窗口期」重要。希腊酸奶 ~10g/100g、鸡胸 ~31g/100g、蛋白粉是补齐工具不是必需品。

B
β-丙氨酸3-6g/天持续 4 周

对 1-4 分钟高强度间歇（如匹克球连续对拉）有中度证据——肌肽储备提升缓冲能力。起效慢，不是即战力。

B
胶原蛋白＋VC15g 胶原＋50mg VC

对肌腱/韧带有针对性证据——如果你有跟腱劳损史，这是必选项。运动前 30-60 分钟空腹服用效果更佳。

✗
BCAA / 谷氨酰胺 / ZMA / 能量饮料

BCAA 在蛋白质总量充足时无额外效果；谷氨酰胺对运动表现无证据；ZMA 是营销产物；能量饮料（红牛/Monster）钠≈0、糖/咖啡因过高——不是运动饮料。

📌 三句话总结

① 打球超 1 小时喝含糖等渗（宝矿力最干净、佳得乐果糖最低、尖叫唯一等渗认证）——糖不是敌人，是钠的搬运工（SGLT1）。
② 不满 1 小时白水就好——久坐喝运动饮料＝纯喝糖水（一瓶 = 1.5 根香蕉的糖）。
③ 离场前 15 分钟到回家 1 小时是补给黄金窗——等渗＋香蕉＋蛋白质，拉伸抽筋就在这里防。
